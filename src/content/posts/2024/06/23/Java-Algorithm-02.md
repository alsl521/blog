# 快慢指针

快慢指针，顾名思义，在链表中，维持两个指针，跳跃速度不同（A跳一步，B就跳两步）。他能做的事情很多，最直观的是寻找链表的中点。还可以判断链表是否有环等等。这里我们先解释快慢指针算法，然后分析它的复杂度。
